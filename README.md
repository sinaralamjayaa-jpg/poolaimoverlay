# Pool Aim Overlay (Android)
Proyek Android sederhana untuk overlay garis bidik manual. Tidak membaca layar, tidak mengubah game, dan tidak mengirim input otomatis.

## Build dari HP melalui GitHub Actions
1. Buat repository GitHub baru.
2. Unggah seluruh ISI folder proyek ini, termasuk folder tersembunyi `.github/workflows`.
3. Buka tab Actions, pilih `Build Android APK`, lalu tekan `Run workflow`.
4. Setelah selesai, buka hasil run dan unduh artifact `PoolAimOverlay-APK`.
5. Ekstrak ZIP artifact dan pasang `app-debug.apk`.

Persyaratan build: JDK 17, Gradle 8.9, Android SDK 35.
